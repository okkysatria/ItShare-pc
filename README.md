---

ItShare is a lightweight Windows utility that turns any local folder into an SMB share accessible via QR code. It eliminates the friction of configuring Windows Network Sharing, guest accounts, or uploading files to intermediate cloud storage.

The Android client connects by scanning the QR code generated by the host. All transfers remain within the local network (LAN / WLAN).

---

## Architecture Overview

Standard Windows file sharing usually requires configuring Local Security Policies, managing network profiles, and exposing SMB port 445 (which often requires Administrator rights and can be blocked by firewalls or ISP routers). 

ItShare takes a different approach:
- **Detached SMB Service**: Spawns an isolated `impacket.smbserver.SimpleSMBServer` instance in a child process bound to a non-standard port (default `4455`). This prevents GUI freezes and isolates the main application from unexpected network drops.
- **Dynamic Ephemeral Credentials**: For each share session, the host generates a cryptographically secure random username and NTLM password via `secrets.token_hex`. Credentials are never reused.
- **Session Lifecycles**: Supports both timed sessions (auto-terminates after a preset duration) and persistent sessions.
- **Access Modes**: Enforces read-only or read-write permissions at the SMB layer before requests touch the host filesystem.

## Requirements

- **OS**: Windows 10 or Windows 11 (64-bit)
- **Python**: 3.10+ (tested against Python 3.11, 3.12, and 3.14)
- **Network**: Host PC and client devices must reside on the same subnet (or client connected via the PC's Wi-Fi hotspot).

## Quick Start

### 1. Installation

Clone the repository and set up a Python virtual environment:

```powershell
git clone https://github.com/your-username/Itshare-pc.git
cd Itshare-pc

python -m venv .venv
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

### 2. Running the Application

```powershell
python main.py
```

### 3. Usage Workflow

1. Select a folder to share via the **Folder Setup** tab.
2. Choose permission level (**Read-Only** or **Read-Write**) and optional session expiry.
3. Click **Start Sharing**. A QR code encoding the session parameters will be displayed on the screen.
4. Scan the QR code using the **ItShare Android** client.
5. To stop sharing, click **Stop Sharing** or close the application. The background SMB process will cleanly terminate.

---

## Network & Firewall Configuration

- **Default Port**: `4455` (TCP).
- If your Windows Defender Firewall prompts for network access on first run, allow access on **Private Networks**.
- To share without an existing router, enable **Windows Mobile Hotspot** in Windows Settings. ItShare can generate a Wi-Fi QR code (`WIFI:S:...;P:...;;`) directly from the interface so mobile clients can connect immediately.

## Wire Protocol Specification

The host application serializes connection metadata into a compact JSON string encoded into the QR code:

```json
{
  "v": 1,
  "host": "192.168.1.50",
  "port": 4455,
  "share": "SHARED",
  "user": "u9a1f2c",
  "pass": "d4e8c1b50f7a2391",
  "ro": true,
  "exp": 1774000000
}
```

### Field Definitions

| Field | Type | Description |
|---|---|---|
| `v` | integer | Protocol revision number (`1`). |
| `host` | string | Host IPv4 address on the active network adapter. |
| `port` | integer | Active TCP port where the SMB server is listening. |
| `share` | string | Share name exported by the SMB service. |
| `user` | string | Session username. |
| `pass` | string | Session password (NTLM hash computed internally). |
| `ro` | boolean | `true` if read-only (uploads rejected); `false` if read-write. |
| `exp` | integer | Optional Unix timestamp (seconds) when the share will stop. `0` or absent indicates no expiration. |
